# Classification NAEMAS
Je vous partage les codes permettant d’obtenir les premiers résultats de la classification NAEMAS.
Ces fichiers incluent :

- Le code NAEMAS, qui implémente l’algorithme de clasification en lien avec la nomenclature.
- Le code HTML, CSS et JavaScript, utilisé pour l’interface et la visualisation des résultats.
- Le code Python, qui contient les scripts de traitement des données et d’automatisation du processus.

L’objectif de ce partage est de rendre accessibles ces premiers travaux afin de faciliter leur réutilisation et leur amélioration. 
Ces fichiers constituent une base initiale et pourront être enrichis par la suite en fonction des besoins et des retours.
